# 开发状态与验证

当前为开发预览，不是已完成 Windows 验收的正式版本。

## 已写入的功能

- 独立的 WPF 普通权限配置入口和无窗口启动入口。
- 程序列表与创建/编辑分为独立页面，支持搜索、启用禁用、删除和创建快捷方式。
- 同一用户会话仅保留一个管理窗口；后续打开和右键导入转交已有窗口，已有填写或预填数据时确认后才覆盖，默认保留。
- 启动结果增加客户端收讫确认，避免执行端提前断开导致成功后误报；收到有效结果后，确认发送失败不会覆盖成功结果。
- 新快捷方式保留环境变量数据块和绝对路径后备，支持调用进程尚无变量时启动。
- EXE/LNK 导入，保留参数文本、起始目录、图标索引及窗口状态。
- 环境变量 Shell Link 数据块、传统右键菜单注册。
- 计划任务 COM 封装，受保护的配置文件，带长度限制的命名管道协议。
- 客户端和服务端身份检查、授权项 ID 请求、逐条处理连接、空闲退出。

## 构建

安装 .NET 10 SDK，在根目录运行：

    dotnet build UACToolBox.slnx -c Release
    dotnet run --project tests/Contracts.Tests -c Release
    dotnet run --project tests/WindowsIntegration.Tests -c Release
    powershell -ExecutionPolicy Bypass -File scripts/publish.ps1

已生成 artifacts/win-x64 开发预览包，需 .NET 10 Desktop Runtime x64。使用 scripts/publish.ps1 -FrameworkDependent 可重建此包；不加此参数则自包含发布（该模式尚未实测）。

发布生成两个入口及配套依赖。复制完整发布目录到受保护目录后再打开配置入口。
开发过程不自动安装计划任务、修改机器环境变量或注册右键菜单。配置界面分别提供这些操作。

## 使用

1. 普通权限打开配置界面，无需 UAC。
2. 在设置页安装计划任务，完成首次管理员授权；更新启动器环境变量，按需注册菜单（系统设置单独授权）。
3. 导入程序或已有快捷方式，核对字段并保存。
4. 创建快捷方式，从普通权限文件管理器启动，验证无重复 UAC 提示。

目标程序和工作目录允许普通权限写入；程序更新后不要求再次授权。仍拒绝重解析路径和非本机 EXE 目标。工具自身及授权配置继续要求受保护的路径。
仅面向同一管理员账户的交互会话；跨用户授权不在支持范围内。

## 本次更新方式

关闭旧配置窗口，等待启动执行端空闲退出后，用新发布目录的完整内容替换原安装文件；已有授权配置无需重建。重新生成快捷方式，使绝对路径后备修正生效。发布只更新构建产物，不自动覆盖已安装文件。

配置入口以 asInvoker 运行，日常打开和复用窗口不再主动请求管理员权限。单实例约束为同一用户、同一交互会话。迁移仍需修复任务、更新变量；旧进程若保留旧变量且旧位置已删除，需要刷新其环境。

## 免 UAC 保存

- 配置界面以普通权限加载受保护配置。保存、删除经同用户同会话的后台任务提交；保存期间禁用编辑并排队外部导入，防止异步结果覆盖新填写。
- 执行端先验证请求者 SID、会话、完整性级别，以及其进程为本安装受保护目录中的 Config.exe，再允许传输配置。配置最大 2 MB，普通启动消息仍为 64 KiB。客户端验证执行端身份和安装路径。
- 执行端重新校验配置归属、条目及目标，沿用修订号检查和原子替换。断连时不自动重复保存；用户重新打开界面核对实际内容。旧版执行端拒绝新版保存协议时提示整体更新。
- 配置目录及 ACL 未放宽。目标 EXE 仍允许普通目录和更新后无需重新授权。
- 首次安装 / 修复、卸载任务、修改系统环境变量或菜单由单次管理员辅助进程处理。辅助入口只接受固定系统操作，并要求授权账户与界面账户一致。
- 这意味着当前用户安装授权后可免再次管理员确认修改高权限启动配置。进程路径校验不是针对同用户进程注入或界面自动化的强隔离边界。
- 新增验证覆盖保存协议、超过 64 KiB 的配置传输及容量上限、无提权配置校验、错误归属和启动器目标拒绝、真实管道拒绝非配置进程、系统操作白名单。实际计划任务提权保存、系统设置授权及 UI 排队交互尚待端到端验收；本轮测试未改动安装目录、任务、机器变量、菜单或正式配置。

## UACToolBox 名称与快捷方式位置

界面标题、产品标识、解决方案及代码命名统一为 UACToolBox。配置、任务、环境变量等已有系统集成标识保持兼容，原入口文件仍为 Config.exe 和 Launcher.exe。

显示名称合并为快捷方式名称，列表和生成文件共用此名称；旧配置的 displayName 字段仍可读取，不自动改名已有条目。新建或导入默认追加一次 _UACTB；自定义名称保留原样，允许输入 .lnk 扩展名，生成时避免重复。校验 Windows 无效字符、保留文件名及路径穿越。

创建位置默认使用当前用户桌面，选择自定义立即打开文件夹选择器，并保存所选目录；取消且未选择过目录时恢复桌面。保存并创建直接写入所选目录，若文件存在先提示覆盖，默认否。修改名称或位置只影响后续创建，不删除此前生成的快捷方式。

新增检查覆盖旧名称及启用状态兼容、自定义目录持久化、默认名称、文件名验证、桌面定位、实际自定义目录生成、丢失目录拒绝、手动输入目标自动命名及保留自定义名称。文件夹选择器和覆盖确认的交互仍待手动验收。
